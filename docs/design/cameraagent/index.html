Shared boundary

All concepts are anonymous and read-only. Exact coordinates, serials, credentials, queues, storage, errors, and detailed health remain operator-only.

Shared behavior

The last valid image remains visible if updates stop. Image freshness and weather freshness are independent. Local event candidates are explicitly provisional.
