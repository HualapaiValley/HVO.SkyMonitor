Security boundary

Proposed safe behavior

No public self-registration

The current application exposes a generic registration form. That behavior must be removed or owner-gated before deployment on an untrusted network.

Recovery is deployment-managed

This CameraAgent does not currently deliver password-reset email. Restore owner access by correcting protected configuration and restarting the host.

Target startup reconciliation promotes only the configured owner and removes stale owner privilege from prior accounts.
