The target workflow must coordinate four explicit steps before this action can be enabled.

  1. Revoke the active registration in LogicHost with owner revalidation.
  2. Persist a non-secret local marker containing that registration identity and last-known state.
  3. Evict loaded credentials and cached tokens, then delete the encrypted secret file.
  4. Report Restart required; the operator restarts CameraAgent through its deployment supervisor.

The current host only deletes the file, so this safer action remains withheld.
