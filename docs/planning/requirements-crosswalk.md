# Requirements Crosswalk

This crosswalk maps normative sources to the authoritative project phases,
roadmap initiatives, GitHub issues, and retained specifications. It prevents
planning consolidation from dropping detailed behavior and prevents subsystem
documents from becoming competing status authorities.

`docs/roadmap.md` owns portfolio initiative IDs, horizons, and top-level epic
mappings. `docs/project-plan.md` owns virtual-first scope, architecture, phase
order, aggregate phase status, and completion. The retained source in this table
owns detailed subsystem behavior. GitHub issues own live issue/PR execution
state and evidence.

The central application and combined deployment requirements record retired
scope under #1848 and #2061. The linked historical revisions retain their
specifications and evidence.

#### Disposition of Earlier `#1191` Reference Failures and Unrelated `#520` Holds

- **Earlier Python ball-arithmetic S4 reference timeout (`exit 124` at 600 s on `cdbb5d83`, 598.95/599.93 s in `sample_piece`/`refine`; unaccepted):** Superseded by the zero-production-import C# analytic/root-based oracle (`IndependentAnalyticClippingOracle.cs`) using closed-form great-circle plane/cone roots, multi-stage horizon/refraction-floor/domain/sensor isolation, 60-iteration golden-section extremum search, 52-bit bisection, and adaptive chord-sagitta subdivision (`ReferenceSagittaTolerancePixels = 1e-4 px`, self-verified `< 0.0005 px` on both 40 px and 4,000 px circles, failing explicitly via `InvalidOperationException` if its sagitta bound cannot be met at maximum depth). Full suite runs deterministically in seconds.
- **Source-identified antipodal / near-antipodal outline domain failure:** Reproduced and handled cleanly in `DeepSkyOutlineSampler` (`AntipodalExclusionMarginRadians = 1e-5 rad`, refusing `>= π - 1e-5 rad` edges without aborting sibling objects) and `DeepSkyCatalog.ComputeOutlineReachDegrees` (`180°` conservative reach for antipodal edges).
- **Horizon-graze visibility drop, refraction-floor discontinuity crossing, unmet max-depth error-bound silence, and curved sensor-boundary excursion misclassification (F4, F6 & F18):** Resolved in `ResolvedFootprintSampler.SampleBoundarySafe` / `AppendBoundarySafeCurve` and `IndependentAnalyticClippingOracle` with sequential geometric-horizon, Bennett refraction-floor (`MinimumAltitudeDegrees`, pinning each branch to its smooth one-sided limit and preventing cross-branch stitching), optical-domain, and golden-section sensor/aperture excursion isolation, plus explicit error-bound observability (`SampleBoundarySafe` and the oracle throw `InvalidOperationException` when a chord cannot meet tolerance within subdivision depth; `DeepSkySceneProjector` degrades only that single extent to `FootprintLimit`, and `DeepSkyOutlineSampler` returns `InvalidGeometry` without aborting siblings).
