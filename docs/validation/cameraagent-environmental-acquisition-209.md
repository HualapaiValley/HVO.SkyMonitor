# CameraAgent Environmental Acquisition Acceptance (#209)

## Scope

Issue #209 adds configuration-driven virtual environmental sources, bounded
periodic/capture/on-demand acquisition, authoritative targetless local history,
temporal capture association, owner operations, health, and runtime evidence to
CameraAgent. Local SQLite commit is the publication boundary. Optional central
delivery is a separate consumer and never owns local acquisition.

Physical weather stations, cloud sensors, SQM hardware, forecast/provider
selection, weather-triggered capture safety, and final #210 overlay/pipeline
composition are excluded. Sky temperature remains undefined; no value is
emitted or mapped to ambient temperature.

## Workloads

| Workload | Evidence |
| --- | --- |
| A1 generation | 5 warmups and 30 measured 12-kind deterministic batches with aggregate canonical SHA-256. |
| A2 durability | W3M 10,000 targetless rows in 100-row batches; records throughput, median/p95 commit latency, CPU, allocations, RSS, SQLite bytes, WAL/checkpoint, statements, and transaction boundaries. |
| A3 history/association | 1,000/10,000-row indexed keyset history, first/middle/late pages, concurrency 1/10/50, query plans, payload bounds, and deterministic fresh/stale/missing/contradictory association. |
| A4 triggers | 360 logical captures over 30 minutes, fixed-rate periodic work, six pinned captures, exact every-third/regime behavior, and observed 4/1 concurrency. |
| A5 outage/recovery | 600 local facts, restart after 300, central capacity 100, no local loss, then duplicate-free projection/drain and zero final backlog. |
| A6 faults | Before/after local commit, timeout, source throw, invalid result, queue capacity, database lock, restart, replay, active retention holds, and delivery outage. |

Initial ceilings are p95 below 1000 ms for indexed 10,000-row local history,
p95 below 5000 ms for authenticated history at concurrency 50, response payload
at most 512 KiB, working-set growth at most 256 MiB, and no queue or retained
collection beyond configured bounds. A missed ceiling requires correction or an
explicit retained limitation.

## Durability

The journal is
`<RawIngressRoot>/.environment/environmental-observation-outbox.db`, schema v3.
It uses WAL, `synchronous=FULL`, bounded busy timeout, integrity checks, and path
defenses. V2-to-v3 migration backfills every surviving delivery row
transactionally and idempotently. Acknowledged v2 rows were already deleted and
cannot be reconstructed; no replacement facts are invented. Newer schemas fail
closed.

Age/count/byte retention is independent of central delivery. Active lineage,
raw-capture association, and waiting/staged projection holds survive ordinary
and pressure retention. Source schedule, attempts, the last capture solar
regime, on-demand leases/receipts, and association sets survive restart.
Expired abandoned command leases are reclaimable and old expired rows are
bounded; new commands are rejected explicitly at capacity.

## Standalone And Central Boundaries

`EnvironmentalHistoryAndOwnerSurfaceRecoverWithoutAnyCentralServiceAsync` runs
the production Kestrel CameraAgent with all 12 sources and central mode disabled.
It verifies local acquisition, protected API/page access, restart recovery, and
zero recorded central HTTP attempts while LogicHost, SQL Server, Redis, and
MinIO are absent.

Central integration tests separately prove v1/v2 acceptance, v2 rig binding,
duplicate receipt replay, local-count independence, target freezing, outage,
restart, and recovery. A central provisioning, capacity, authentication, or
transport failure cannot roll back a committed local fact.

## Operator Boundary

The owner-only `/environmental` page shows source state, last result, age, next
poll, failures, attempts, and bounded history. Reads require operations-read.
On-demand acquisition requires operations-mutate, owner identity, antiforgery,
and `Idempotency-Key`; conflict returns `409` and busy/capacity returns `429`.
References and cursors are protected and filter-bound. Anonymous/non-owner,
antiforgery, paging, and sanitized-error behavior are integration tested.

The normative runtime contract is
[`cameraagent-environmental-acquisition-runtime-signals.json`](cameraagent-environmental-acquisition-runtime-signals.json).
It reserves event IDs 2520-2529, lists every metric/span and bounded value, and
defines independent `environmental-acquisition` health and privacy fields.

## Limitations

- The A3 in-process harness measures indexed store concurrency; authenticated
  Kestrel history has functional acceptance but does not yet emit a separate
  1,000/10,000-row concurrency-50 timing series. The artifact must retain
  `AuthenticatedCeilingExecuted=false` rather than claiming that ceiling.
- Performance results are virtual/local baselines, not physical sensor,
  weather accuracy, or cloud-safety claims.
- Final corner annotation and complete weather/cloud rendering composition are
  owned by #210; #209 supplies durable, explicit association inputs.
