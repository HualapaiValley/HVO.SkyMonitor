existing recorded scratch directory, archives the exact baseline source and

versions and the existing Skia native assets. Run:

```bash

```

Each representation runs three trials of five warm-ups and 30 measured
operations, concurrency one, `DOTNET_PROCESSOR_COUNT=2`, Release, pinned SDK
10.0.402 and identical scene/base input. It records CPU, managed allocations,
working set, median/p95 producer+render latency, per-operation timing/GC
observations, primitive counts, fonts and input/output checksums. There is no
queue, arrival stream, storage I/O or backlog at this boundary. It compares
actual baseline v13, current v13, new default v14 and changed v14. The shared

use that dependency on both sides. The failed attempt remains in
